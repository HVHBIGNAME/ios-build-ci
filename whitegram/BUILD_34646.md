## Profile lifecycle

Metadata preferences and localization changes refresh the open profile. The
registration adapter invalidates old answers on peer, session, access and profile
mutation changes, and cancels outstanding work at teardown. It does not infer
dates from user IDs. Exact dates retain `DD.MM.YYYY`; approximate dates retain
their `~` prefix and available month/year precision.

The original persistent registration caches and known-user discovery/prefilter
are not reproduced. Live service access and actual-device profile behavior still
need verification; service failure supplies no fabricated date.

## Icon resources and refresh

The 40 Settings PNGs and 66 launcher PNGs are byte-for-byte recovered from IPA
SHA-256 `bd6d3a13046d5857c1389e2d794c4c2ca44cee89bb22880004bd77f84fe29837`.
The resource manifests retain original paths and hashes. Launcher choices are
ordered Blue, New2, New1, Black, BlueClassic, BlackClassic, BlueFilled, BlackFilled.
All eight are explicitly non-default/non-premium. Turning the switch off hides
the choices without changing the currently selected system icon.

Main Settings refreshes through the appearance signal; the separate icon picker
refreshes on preference changes and activation, using the visible application
bindings intersected with the installed device-specific plist. System icon
selection still uses UIKit and reports its actual completion/current value.

The resource installer extends only the main app's Bazel resources/alternate
icons. WGPrimary and all thirteen WG alternatives remain. Original New1/New2
plist entries named nonexistent files; generated references now use the actual
original PNG filenames. Details are in
[`resources/stock-launcher-icons/README.md`](resources/stock-launcher-icons/README.md).

`verify_ipa.py --require-restored-icons` checks both device families, resolving
file references and all 106 recovered PNGs at the main bundle root. Xcode
recompression is accepted only when dimensions and premultiplied RGBA pixels
remain identical. Nested/missing/replaced files fail verification.
